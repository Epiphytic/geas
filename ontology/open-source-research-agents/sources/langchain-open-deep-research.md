# LangChain Open Deep Research source card

Observed on 2026-08-03 at default-branch commit d337ae32ed4ff8f4c6fbe192ba3bf1b2d6610799.

Open Deep Research is documented as a configurable open-source research agent supporting multiple model providers, search tools, and MCP servers.

Its documented model roles include search-result summarization, research, compression, and final-report generation.

The project publishes a Deep Research Bench evaluation workflow whose leaderboard metric uses an LLM judge against expert-created reference reports.

The current implementation is report-oriented and the repository retains legacy plan-and-execute and supervisor-researcher implementations.

The repository identifies its software license as MIT.
