# PaperQA2 source card

Observed on 2026-08-03 at default-branch commit d7675d7b7eddeb3535e8c260399c5bbeeb818c50.

PaperQA2 is documented as retrieval-augmented generation over scientific documents with grounded answers and in-text citations.

It indexes local PDFs and other text-bearing formats, enriches metadata through scholarly services, chunks evidence, retrieves and ranks contexts, and generates an answer.

PaperQA2 documents contradiction detection and retraction checks as scientific-research capabilities.

Its persistent local state includes document indexes and prior answers.

The default retrieval path uses embeddings, while sparse keyword retrieval and disabling evidence retrieval are documented alternatives.

The repository identifies its software license as Apache-2.0.
